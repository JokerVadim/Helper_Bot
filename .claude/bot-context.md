# Telegram бот — полный функционал

## Архитектура

```
bot.py              — точка входа, handle_message, обработка фото/документов/локаций
├── ai.py           — Groq (LLM) + Tavily (поиск) + память + Gemini/OpenRouter fallback
├── db.py           — SQLite ORM (все таблицы)
├── config.py       — константы
├── keyboards.py    — все клавиатуры (show_main_menu, btn_menu, btn_cancel)
├── shortcuts.py    — сокращения для быстрых команд (спс, сори и т.д.)
├── tools.py        — AI tool definitions (инструменты для Groq function calling)
├── handlers/
│   ├── callbacks.py   — ВСЕ callback_data обработчики (~2400 строк)
│   ├── commands.py    — команды /start, /cancel, /status, /rub, /milk и т.д.
│   ├── session.py     — управление процессами (start_process, finish_process, processes)
│   ├── reminders.py   — планировщик напоминаний (JobQueue) + tag migration
│   ├── inline.py      — inline-режим (@bot список, курс, погода...)
│   └── processors/    — логика по модулям
│       ├── cards.py       — отображение/создание карт
│       ├── documents.py   — отображение/создание документов
│       ├── lists.py       — отображение списков
│       ├── locations.py   — отображение локаций
│       ├── notes.py       — отображение заметок
│       ├── reminders.py   — отображение напоминаний
│       ├── birthdays.py   — дни рождения (+ уведомления)
│       ├── weather.py     — погода (Open-Meteo, AQI)
│       ├── daily_summary.py — сводка дня (виджет)
│       ├── widget.py      — настройки времени виджета
│       ├── tag_ui.py      — универсальный UI тегов (пикер с чекбоксами)
│       ├── misc.py        — сумма, поиск, PIN-код
│       └── __init__.py    — регистрация обработчиков
├── utils/
│   ├── __init__.py    — md(), _pad(), is_authorized()
│   ├── emoji_utils.py — эмодзи для элементов
│   ├── list_display.py — форматирование списков
│   ├── time_utils.py  — парсинг времени, повторы, часы
│   └── tags.py        — normalize_tag_name()
└── logs/              — ежедневные лог-файлы bot_YYYYMMDD.log
```

## 📋 Списки

### Меню списков (2 уровень)
```
[✚ Добавить] [✏️ Название]
[🔗 Поделиться]
[🏠 Меню]
```

### Возможности
- **Создание** — кнопка "✚ Добавить" → ввод названия → добавление элементов по одному
- **Просмотр** — нажатие на список открывает элементы с эмодзи
- **Добавление элементов** — в списке кнопка "Добавить" → ввод текста
- **Чекбоксы** — нажатие на элемент переключает выполнен/не выполнен (☑️/☐)
- **Эмодзи-подсказки** — Groq подбирает эмодзи для новых элементов (`_suggest_emoji`)
- **Сортировка** — по алфавиту (кнопка A→Я), порядок сохраняется в `item_sort_order`
- **Скрытие выполненных** — кнопка скрыть/показать выполненные элементы
- **Копирование** — копирование всех элементов списка в сообщение
- **Переименование** — кнопка "✏️ Название" → выбрать список → ввести новое имя
- **Шеринг** — `/share список_id @username` — дать доступ другому пользователю
- **Отзыв доступа** — `/unshare список_id @username`
- **Просмотр шеринга** — `/shared` — списки, к которым есть доступ
- **Удаление** — через редактирование: выбор списка → подтверждение → удаление

### Типы списков
- `personal` — личный список
- `shared` — расшаренный (управляется флагом `shared_with`)

### Хранилище
- Таблица `lists` (list_id, type, name, user_id, sort_order, created_at)
- Таблица `items` (id, list_id, user_id, text, checked, sort_order, emoji)
- Таблица `shared_lists` (id, list_id, owner_id, shared_with_username, shared_with_id)

## ⏰ Напоминания

### Меню напоминаний (2 уровень)
```
[✚ Добавить] [🗑 Удалить]
[🏠 Меню]
```

### Меню в режиме удаления
```
[✚ Добавить] [✅ Готово]
[🏠 Меню]
```

### Типы напоминаний
| Тип | Описание | Тег (авто) | Кнопка |
|-----|----------|-----------|--------|
| 🔔 Одноразовое | Срабатывает 1 раз | разовое | `remtype_none` |
| ⏱ Каждые N минут | Повтор с интервалом | интервал | `remtype_minutes` |
| 🔁 Ежедневное | Каждый день в то же время | ежедневно | `remtype_daily` |
| 📅 По дням | По выбранным дням недели | по дням | `remtype_weekly` |
| 📆 Ежемесячное | Каждый месяц в указанный день | ежемесячно | `remtype_monthly` |
| 🎂 Ежегодное | Каждый год (дни рождения) | ежегодно | `remtype_yearly` |

- **Авто-теги**: при создании напоминания автоматически добавляется тег по типу
- **Теги как fallback**: если тег "разное" есть — удаляется при добавлении конкретного тега

### Создание
1. Выбор типа → ввод времени → ввод текста → сохранение
2. Для "Каждые N минут": ввод числа минут → ввод текста → запуск
3. Для ежемесячных: ввод числа месяца (1-31) → время → текст
4. Для ежегодных: ввод даты (ДД.ММ) → время → текст

### Кнопки при срабатывании
- **Одноразовые/ежедневные/ежемесячные/ежегодные**: [🔇], [+10м], [+1ч], [Завтра], [OK]
  - 🔇 — отключить повторения
  - +10м, +1ч, Завтра — отложить (snooze)
  - OK — удалить сообщение
- **Каждые N минут**: [❌] [OK] — ❌ удаляет напоминание, OK продолжает цикл

### Детали напоминания (3 уровень)
```
⏰ Название
⏱ Время: 10:00
🔁 Каждый день
[✏️ Название] [✏️ Время]
[◀️ Назад] [🏠 Меню]
```

### Восстановление после перезапуска
- Все активные напоминания восстанавливаются из БД
- Пропущенные отправляются как "Пропущенное напоминание"
- Повторяющиеся — пересчитывается следующее время

### Хранилище
- Таблица `reminders` (id, chat_id, rid, text, fire_at, is_timer, repeat_type, minutes, delivered, notify_before_minutes)
- Таблица `reminder_tags` (id, user_id, name, normalized_name) — UNIQUE(user_id, normalized_name)
- Таблица `reminder_tag_links` (reminder_id, tag_id) — PRIMARY KEY

## 🏦 Курс валют

### Возможности
- **RUB (Kapitalbank)** — парсинг `<pre>` блока с kapitalbank.uz
- **USD (Agrobank)** — JSON API agrobank.uz
- **Два курса сразу** — открытие "🏦 Курс" показывает и RUB, и USD параллельно
- **Расчёт** — `курс * текущая_сумма` (если сумма задана)
- Использует `cloudscraper` для обхода защиты Kapitalbank

### Команды
- `/rub` — текущий курс (RUB + USD)
- `/rub 10000` — сколько рублей в 10 000 сум
- Кнопка в главном меню

### Inline mode
- `@bot курс` — оба курса
- `@bot rub` / `@bot usd` — отдельно

- **Дней до ДР** — показывает количество дней или 🎉 если сегодня
- **Авто-поздравление** — каждый час проверяет, отправляет в заданное время
- **Предупреждение за день** — опционально, включается/выключается
- **Настройка времени** — своё время для каждого пользователя
- **Редактирование** — имени и даты (с годом или без)
- **Inline mode** — `@bot днюха` показывает ближайшие
- **Интеграция со сводкой** — дни рождения показываются в утренней сводке

### Система уведомлений
- Независимая от напоминаний (своя проверка `check_birthdays()`)
- Job: каждые 60 минут проверяет birthdays
- Проверяет: сегодня (поздравление) + завтра (предупреждение, если включено)
- Сравнивает с точным временем HH:MM из настроек пользователя

### Хранилище
- Таблица `birthdays` (id, user_id, name, birth_date)
- Таблица `birthday_settings` (user_id, notify_time, notify_advance)

## 🤖 AI (Groq + Fallback)

### Модели
| Модель | Использование | Статус |
|--------|--------------|--------|
| `llama-3.3-70b-versatile` (Groq) | Основной чат + tool calling | 🟢 Основная |
| `llama-3.1-8b-instant` (Groq) | Лёгкие задачи (эмодзи, поисковые запросы) | 🟢 |
| `gemini-2.0-flash` / `gemini-1.5-flash` | Fallback при лимите Groq | 🟡 Если ключ есть |
| `gemma-2-9b-it:free` / `llama-3.3-70b-instruct:free` / `qwen3-8b:free` (OpenRouter) | Fallback при лимите Groq | 🟡 Если ключ есть |

### Режимы работы
1. **Обычный диалог** — `_ask_groq_with_history()` — ответ с учётом истории
2. **Поиск** — если "найди" → Tavily → Groq с контекстом
3. **Tool Calling** — Groq может вызывать инструменты:
   - `get_summa` — показать/изменить сумму
   - `get_notes`, `create_note`, `update_note`, `delete_note` — заметки
   - `get_lists`, `get_list_items`, `add_items`, `check_item`, `delete_item` — списки
   - `get_reminders`, `create_reminder`, `delete_reminder` — напоминания
   - `get_birthdays`, `add_birthday`, `delete_birthday` — дни рождения
   - `get_locations`, `delete_location` — локации
   - `get_documents`, `get_document_tags` — документы

### Память (Groq Memory)
- **Долговременная память** — таблица `user_memories` (user_id, key, value)
- **Авто-сохранение** — Groq может сохранять факты через `[MEMO: ключ = значение]`
- **Явное сохранение** — "запомни молоко = 80 сум"
- **Просмотр памяти** — "что ты помнишь" показывает все записи
- **Очистка памяти** — "забудь всё"
- **Инжект в контекст** — до 15 последних записей в системный промпт

## 🎨 Интерфейс и форматирование

### Функция `_pad()`
```python
def _pad(text: str, width: int = 32) -> str:
    """Дополнить строку невидимыми символами до width."""
    return text + "\u3164" * max(1, width - len(text))
```

### Функция `md()`
```python
def md(text) -> str:
    from telegram.helpers import escape_markdown
    return escape_markdown(str(text), version=1)
```

### Форматирование времени
- `parse_time_arg()` — парсинг "5m", "1h30m", "300", "10:00"

- `_repeat_icon()` / `_repeat_label()` — иконка и название типа повтора
- `hours_to_str()` — форматирование секунд в "1ч 30м"

## 🔄 Запуск и обслуживание

### Запуск
```bash
python bot.py          # обычный запуск
start_bot.bat          # Windows: убить старый процесс + запустить новый
```

### Логирование
- Файл: `logs/bot_YYYYMMDD.log` (ежедневная ротация)
- Консоль + файл
- Кодировка: UTF-8 (принудительно для Windows)

### Авто-задачи при старте
1. Backup БД → `backups/bot_YYYYMMDD_HHMMSS.db`
2. Инициализация БД (создание таблиц)
3. Валидация API: Groq → Tavily → Gemini → OpenRouter
4. Восстановление напоминаний (через `restore_reminders`)
   - Пропущенные → отправляются немедленно
   - Повторяющиеся → пересчёт времени
5. Миграция тегов (например, "в день" → "по дням")
6. Проверка дней рождения (через `check_birthdays`)
7. Проверка документов на обновление (через `check_documents_refresh`)

### Обработка ошибок
- `asyncio.TimeoutError` — таймаут поиска (30 сек)
- `telegram.error.Conflict` — конфликт polling
- Rate limit 429 → fallback на Gemini/OpenRouter
- Все исключения логируются с `logger.error`

```
│   └── 🔐 PIN-защита (если включена)
├── 📄 Документы (2 ур.) → документ (3 ур.) → теги (3 ур.)
│   └── 🔐 PIN-защита (если включена)
├── 💰 Сумма (2 ур.) → изменение/сброс
├── 🏦 Курс (2 ур.) → RUB + USD
├── 📍 Локации (2 ур.) → локация (3 ур.) → сортировка (3 ур.)
│   └── 🏷 Теги — пикер с чекбоксами
├── 🎂 Дни рождения (2 ур.) → детали ДР (3 ур.)
│   └── ⏰ Настройки (время, предупреждение за день)
├── 🌤 Погода (2 ур.) → детали погоды (сегодня/неделя)
│   └── ✏️ Редактирование (название, координаты, основная)
└── 🧹 Очистка (2 ур.) → подтверждение
```

### Принципы навигации
- **2 уровень**: кнопка "🏠 Меню" (без "Назад")
- **3 уровень**: кнопки "◀️ Назад" + "🏠 Меню"
- **Режим удаления**: кнопка "🗑 Удалить" заменяется на "✅ Готово" в том же ряду
- **После редактирования**: возврат в исходное меню

### Общие кнопки
- `btn_menu()` — "🏠 Меню" → `callback_data="main_menu"`
- `btn_cancel()` — "🔒 Отмена" → `callback_data="cancel"`
- `btn_back(handler)` — "◀️ Назад" → `callback_data="back_to_{handler}"`

## 📝 Заметки по разработке

### Важные файлы
- **callbacks.py** (~2400 строк) — самый большой файл, содержит почти всю логику кнопок
- **processors/** — разбиение логики по модулям
- **tag_ui.py** — универсальный UI тегов для заметок, напоминаний и локаций

### Особенности
1. Для всех `edit_message_text` используется `_pad()` для единой ширины сообщений
2. Номер карты копируется через `copy_to_clipboard` (WebApp) или inline-кнопку
3. Документы отправляются как пересланные сообщения (копия файла)
4. Локации показываются как встроенная карта Telegram
5. Повторяющиеся напоминания используют `next_repeat_time()` для расчёта следующего срабатывания
6. Режим "Lockdown" блокирует всех, кроме whitelist
7. Эмодзи для элементов списков подбираются через Groq API (`_suggest_emoji`)
8. Open-Meteo — бесплатный API погоды, не требует ключа
9. Reverse geocoding — через Nominatim (OpenStreetMap)
10. PIN-блокировка — 3 попытки, затем 1 минута ожидания
11. При rate limit Groq (429) — автоматический fallback на Gemini → OpenRouter
12. AI может вызывать инструменты через function calling (сумма, заметки, списки и т.д.)
