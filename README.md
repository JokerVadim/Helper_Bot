# 🤖 Telegram Assistant Bot

Бот-ассистент для Telegram с поиском в интернете и напоминаниями.

## 🚀 Быстрый старт

### 1. Получи токен бота
1. Открой Telegram, найди [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot` и следуй инструкциям
3. Скопируй полученный токен

### 2. Настрой переменные окружения
Создай файл `.env` рядом с `bot.py`:
```env
BOT_TOKEN=токен_бота
TAVILY_KEY=ключ_tavily
GROQ_KEY=ключ_groq
```

Не коммить `.env` и `credentials.json` — это секреты.

### 3. Установи зависимости
```bash
pip install -r requirements.txt
```

### 4. Запусти бота
```bash
python bot.py
```

## 📋 Команды бота

| Команда | Описание | Пример |
|---------|----------|--------|
| `/start` | Показать справку | `/start` |
| `/search <запрос>` | Поиск в интернете | `/search погода Ташкент` |
| `/remind <время> <текст>` | Напоминание | `/remind 14:30 Обед` |
| `/remind <Xm/Xh> <текст>` | Через N минут/часов | `/remind 30m Перерыв` |
| `/timer <секунды> <текст>` | Таймер | `/timer 300 Чай готов` |
| `/t <Xm/Xh> <текст>` | Таймер | `/t 5m Чай готов` |
| `/reminders` | Список напоминаний | `/reminders` |
| `/status` | Статус бота | `/status` |
| `/cancel` | Отменить текущее действие | `/cancel` |

Напоминания поддерживают типы: одноразовые, ежедневные, ежемесячные и ежегодные. У сработавших напоминаний есть кнопки отложить на 10 минут, 1 час или завтра.

Также можно просто написать любой текст — бот его найдёт в интернете!
